# 旧原型与历史素材清理

本轮移除已脱离原版入口、现代版入口及存档服务的旧自绘3D原型：`LegacyApp.vue`、旧组件、`render3d`、旧Pinia状态仓库、旧`core`引擎及其五个专属测试。原版SWF入口与现代版游戏逻辑保留。对应的`three`、`@types/three`、`pinia`依赖一并移除。

同时提交此前已确认无运行或重建引用的八个过期人物文件删除。正式人物包、原版模式素材、现用母图及其已确认的来源链不变。

Git历史按对象编号剔除已经不属于当前版本的旧图片、视频和其他素材版本。当前版本全部对象受保护；代码和文本历史保留，不裁掉空提交或合并关系。提交编号会改变，旧编号到新编号的映射存放在本机`.git/filter-repo/commit-map`。

历史重写在独立镜像仓库中执行，检查当前树完全一致、保留对象集合一致、提交元数据与父子关系映射一致后再应用。原有未提交配置、Python依赖文件改动及私人数据不包含在清理提交中。

历史重写后，旧克隆或旧分支可能重新带回已清理对象。同步远端时应核对旧分支端点，使用明确的租约保护，避免覆盖他人的新提交。
