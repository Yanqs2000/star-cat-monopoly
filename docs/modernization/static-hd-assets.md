# 静态高清素材替换

用户授权使用 GPT 内置生图替换尚未重绘的静态场景与界面图片，保留既有高清成果。工作分支 `feat/static-hd-art` 基于本地 `main` 的 `eda3c57`；不导入人物动作、立绘、神灵贴图或 Blender 文件。事件插图中的人物属于静态插画。

2026-10-18 应用户要求，将当前 120 项已接入素材及必要加载、房屋配准代码合并到本地 `main`。主分支工作目录复用 `.worktrees/non-character-assets`；根目录及建模 worktree 保持原状。完整剩余项和本次合并验证见 `static-hd-remaining.md`。

## 素材与进度

机器清单为 `static-hd-production.json`，记录 142 项独立静态文件任务、原图哈希、重复资源别名、各图完整提示词与生成来源。游乐场两个同图路径分别登记任务、共用生成母版；其余复用主要以别名登记。补查的 12 项为静态骰面与投影，不属于人物头像。主地图扩展另列，尚未完成。运行映射为 `src/modern/data/static-hd-assets.json`。

第一阶段接入 54 份重绘母版，覆盖 59 个运行路径：公司建筑 1、16 种卡牌（17 个路径）、37 幅事件插图（41 个路径）。地产房屋与活动面板继续制作。卡牌和公司建筑运行密度为 4，事件插图为 3；母版原生尺寸均达到相应密度，运行图仅缩小打包为无损 WebP。

母版保存于 `public/modern/hd-static-masters/`，运行图保存于 `public/modern/hd-static/`。使用内置 `image_gen`，没有调用 CLI 或 API 生图。透明图保留生成 alpha；事件插图为不透明。`pending-user-review` 表示尚待最终美术验收，已选择的图片已接入高清模式，不会阻塞继续生产。原版画质继续读取原图。

`register_static_hd_master.py` 防止重复注册已完成任务，检查原图、母版原生密度与画布比例，并保存完整提示词和指纹。`verify:modern-static-assets` 检查 81 个既有素材文件未改动、运行图和母版指纹、透明通道、逻辑尺寸、密度和范围。

四种业主颜色的 1—5 级、两种独立朝向共 40 张房屋已逐级并排核对。同等级、同朝向仅归属色块变化，未观察到屋顶、窗户、侧罐、管道、附楼或底座部件的增减；允许轻微光照与抗锯齿差异。`house-color-consistency.json` 绑定本次核对的母版指纹和 30 组辅助测量；数值不代替逐部件目检或用户最终美术验收。`review_static_hd_houses.py` 只生成诊断对照图，不修改生产图片。

房屋使用生成图完整 alpha，在渲染时按原图可见边界配准，处理透明留白差异，维持原等级高度、占位和落地点；小地图复用同一配准结果。打包密度按实际可见内容提高，配准后仍至少保留 4 倍可见细节。插画与界面画布仍保持原比例；大活动面板按其实际原生能力打包，不能把插值放大算作新增高清细节。

公司对话框旧两版因内容区透明度不正确而未启用，2026-10-19 已重做合格的不透明版本接入。相邻地图 M02 三版仍因道路几何、地块纹样或接缝差异而未启用；母版留在对应目录追溯。既有已验收 5A 四块地图原始字节保持不变。未把这些地图候选或旧图插值当作完成重绘。

## 验证

`tests/e2e/modern-static-art.spec.ts` 使用真实 Pixi MapScene、HandPanel 和 InteractionPanel；覆盖新公司建筑、全部 17 张手牌、全部已接入事件图、卡牌选择、事件确认、原版路径与错误监测。测试场景在 `tests/fixtures/modern-static-art.html`，仅供开发测试。Browser 插件不可用，使用项目 Playwright 配置中的本机 Chrome 与 SwiftShader；功能通过不能作为设备性能结论。

房屋回放在真实相邻地块同时展示四种颜色，依次切换 0—5 级并检查实际魔法门小地图与目的地按钮。三项浏览器回放通过（13.8 秒）；此前完整 640 项单元测试与生产构建通过。新增配准回归包含透明留白比例、原生可见密度、alpha 保留、插画比例保护和小地图加载器校验；最后全量结果应在任务完成前重跑确认。

2026-10-18 本批接入后为 120/142 项静态任务、189 个运行路径。用户指出法院罪名与奖券兑换面板存在不规则白色空缺；检查原生 alpha 后证实是背景内部被误删为透明区域。两张均通过 GPT 内置生图重新生成完整不透明面板，原生母版和打包 WebP 全图 alpha 均为 255，未使用代码补色或修改 alpha。外框之外的极小圆角区域也保留桃色底色，以消除透明处理造成的破损。同批法院被告与判决背景检测到同类问题，亦重做后接入；巫婆、车站候选通过检查后保留。
