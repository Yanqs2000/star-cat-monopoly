## 运行和重建

在本工作区执行 `npm run build:modern` 后用 `npm run preview:modern`；开发模式为 `npm run dev:modern`。`npm run test:e2e:modern` 会自行启动modern开发服务器；原 `npm run test:e2e` 专门检查原版入口，二者配置分离。

地图数据重建：`npm run data:modern`。

离线素材重建需要Python/Pillow和已校验的JPEXS 26.2.1；指定 `FFDEC_JAR` 和可用 `FFDEC_JAVA` 后执行 `python3 scripts/export-modern-assets.py`。已生成的PNG/JSON纳入版本控制，日常启动不需要Java、反编译器或Python。
