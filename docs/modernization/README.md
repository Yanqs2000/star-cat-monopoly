## 本次结论

已获得足够的程序与素材证据，可以开始第一批现代版本实现；但还不能宣称全部规则、所有特殊状态和所有动画已被验证。后续每批实现都要依据原版源码定位、受控样例和实际操作继续确认。

- 原始 13 个 SWF 哈希与基线一致。
- JPEXS 26.2.1 成功导出 877 个脚本片段、13,379 行；主程序占 519 个片段、13,021 行。导出成功不代表反编译结果在所有语义上都等价。
- 数据表与地图可直接提取：43×41 网格、56 块住宅地、16 条街道、41 条运气事件。
- 原版共有 5,309 个位图定义、825 个精灵定义；这两个数字都不是独立角色或动画帧数。
- 主地图是 2700×2552 的合成底图，许多固定建筑已经烘焙在图内；动态建筑另行叠加。
- 已导出卷毛四方向行走样本，每方向 24 帧，保留真实 alpha。19 段有效音频可复用。
- 关键风险是时间轴与规则耦合、动态分派、随机数与视觉效果共用、数组字段语义，以及原版自身的异常行为。

## 已确认的产品边界

| 项目 | 决定 |
|---|---|
| 游戏实现 | 新架构实现相同功能，不继续把旧 SWF 包装成正式新版 |
| 原版 Bug | 允许修复；先复现，记录与原版的差异，不把平衡性偏好当成 Bug |
| 美术 | 可以重绘，但尽量保持原版造型、比例、配色、动作和表达 |
| 设备 | 电脑网页，不做手机触屏适配；保留 4∶3 游戏区域和全屏 |
| 游戏模式 | 单机使用，不做网络多人对战 |
| 存档 | 后端保存，手动存档、读档，不做自动存档，不兼容旧存档 |
| 声音 | 沿用原版音乐、音效，核对触发时机 |
| 部署 | 先本地逐批验收，最后部署服务器 |
| 验收 | 每批交付结果和证据，用户通过后才进入下一批 |

第一阶段分析分支为 `analysis/modernization-baseline`；改造前提交 `50981d3d72d5f786f3d2923efc396b94f67f4406` 保持不变。当时没有修改正式游戏源代码、原始 SWF 或高清候选图，也没有开始部署。
