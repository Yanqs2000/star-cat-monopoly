# Non-character Assets 13–17 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将13—17制作成保持原游戏时序、可在真实游戏中连续播放的高清非人物特效。

**Architecture:** 原始SWF与运行清单定义锚点、阶段和行为时点；固定高清母版配合确定性连续运动、遮罩及分层特效。复用01—12独立批准清单与画质替换入口，源清单先验证，高清仅替换显示，原版和人物保持原样。

**Tech Stack:** TypeScript、Vue、Pixi、Pillow无损打包、JPEXS源结构分析、Vitest、Playwright、本地Chrome；GPT内置生图仅用于必要的固定母版。

**Spec:** `docs/modernization/non-character-13-17-analysis.md`

## Global Constraints

- 用户范围：13—17，非人物；后续用户目标“完成13-17”已授权制作与实现；用户已于2026-10-29视觉验收并明确授权合并主分支。
- 原时长：card-gain50／30秒；ticket-gain30／30秒；fog19／30秒，兼容18帧调用；explosion60／30秒；rocket80／30秒。
- 60fps目标输出分别100、60、38、120、160显示采样，不改变业务时钟和事件发生时点。
- 不用逐帧独立生图；禁止把低分位图放大当作新增高清细节；保持透明背景和原锚点。
- 修改入口：`src/modern/features/assets/approved-artwork.ts`与`src/modern/data/non-character-effects.json`候选索引（保持01—12批准JSON不动）；运行资源只放`public/modern/hd-static/`，制作与审阅资料不进入生产构建。
- 原版清单、人物资源及无关工作不改；执行前验证Node24.19.0版本要求和实际运行版本，不擅自升级依赖。

## Review Focus

- 单次动画末帧残留：结束时正确消失并释放，不错误循环。
- 透明烟雾：浅／深背景无黑边，彩色地图没有矩形底色。
- 第15帧后交互与18／19帧分支：保持已有开窗和按钮可用时点。
- 火箭和爆炸同时创建：显示错峰必须有原版依据，不拖延业务结果。
- 暂停、倍速与切换画质：状态、锚点、运动相位和资源清理一致。
