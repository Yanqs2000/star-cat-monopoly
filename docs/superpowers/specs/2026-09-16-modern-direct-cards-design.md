# 3A 直接结算卡牌设计

整体目标仍是完整3A。此子模块实现无需世界碰撞调度的12种可达卡：信用、控骰、购地、炒地、拆屋、天使、恶魔、怪兽、均富、均贫、停留、查税。其余障碍、地雷、飞弹、招神、送神会由世界状态模块接通；不能因拆分而关闭。

使用现有玩家和产权作为唯一资金/地块来源，增加独立手牌、信用、一次骰子覆盖、停留标记和动态地价数据。输入只含玩家、手牌槽与选择，不接收价格或任意现金改变量。返回新快照、消费/失败原因及受影响实体，由统一控制器随后串行提交。

原卡逻辑来自phase-3a-cards-evidence.md和原usecard对应处理帧。额外核对：天使新建时先建立**显示等级0**的原房屋，再把数据等级加一次，所以无主0级最终为1级，并非2级。招神原card21也明确写7天（属后续世界模块）。原信用计数器使用Number，核心仅要求有限数且在0至可用额度内，不擅自要求整数。空屋主账户moneydate[0][2]原始为100000；购地卡对无主地的付款记录在该备用账户，不凭空丢弃。

现有物业模块增加可选动态地价输入，缺省保持2C原地价。合法事件可导致负现金而存款仍足够，因此现金校验放宽为有限值；购地仍需现金足额，租金保持原“先现金、差额入存款”的结果，不擅自抹掉现金负债。普通神灵修正将在世界整合时增加，不能混进固定地价。

目标使用源网格记录类型和原ordinal字段，不能把原记录[3]奇偶错误写成全局ID奇偶。地产目标支持道路和其配对建筑格，玩家目标必须其他玩家精确占据原ordinal为奇数的格。全屏鼠标坐标转换由后续UI负责；本模块只接受原网格坐标。

取消在控制器提交前保持原快照，不调用结算。本模块目标失败不耗卡；信用卡成功也不耗卡。其他本模块成功只移除选中的那一张，重复命令由控制器阶段门限制。
