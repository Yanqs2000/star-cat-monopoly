# 星猫大富翁 0.2.0-beta.1 · 高清桌面测试版

安装后直接双击运行。高清地图、人物、图集、声音和本机手动存读档均随应用提供，不需要安装 Node.js、Python、Java，也无需运行终端命令。首次开始对局需要等待本机素材装配。

## 下载哪个文件

| 系统 | 安装包 | 最低运行系统 |
|---|---|---|
| Mac Apple Silicon（M 系列） | `StarCatMonopoly-0.2.0-beta.1-mac-arm64.dmg` | macOS 13 Ventura |
| Mac Intel | `StarCatMonopoly-0.2.0-beta.1-mac-x64.dmg` | macOS 13 Ventura |
| Windows 64 位 Intel/AMD | `StarCatMonopoly-0.2.0-beta.1-win-x64-setup.exe` | Windows 10 |

最低系统要求来自 Electron 45；实际安装测试的系统版本和架构以本次 Actions 记录为准，不代表已经在每个旧系统上人工验收。

Mac 打开 DMG 后将应用拖入“应用程序”目录。Windows 运行安装器，按提示选择当前用户的安装目录。关闭最后一个窗口即退出游戏，不会留下本地服务。

## 首版签名情况

这是测试版：Windows 安装包未使用开发者证书签名，Mac 为临时签名、未完成 Apple 公证。系统可能显示无法验证开发者或来源的提示；请先核对本页来源与 `SHA256SUMS.txt`，再按系统提供的方式决定是否允许运行。不需要也不建议全局关闭系统安全保护。

Mac 如被阻止，可在尝试打开后查看“系统设置 → 隐私与安全性”中该应用的提示。正式开发者签名、公证和自动更新不包含在首版中。

## 存档

- Mac：`~/Library/Application Support/StarCatMonopoly/saves.sqlite`
- Windows：`%APPDATA%\StarCatMonopoly\saves.sqlite`

三个槽位只在手动保存时写入；关闭、覆盖安装和移除程序本体不应删除该目录。桌面版使用独立存档位置，不会自动导入或修改源码版项目目录下的 `.data/saves.sqlite`。备份时先完全退出应用，再复制整个存档目录。

## 验证与校验

每个安装包必须在对应系统/架构的原生 runner 上完成安装、默认高清启动、开局掷骰、手动保存/关闭/重启读取，以及同版本覆盖安装保留存档。Mac 额外检查应用签名完整性和只读安装目录；Windows 使用 NSIS 静默安装/卸载验证。校验脚本拒绝缺失平台、不同来源提交、失败的安装记录或达到 2 GiB 的附件。

`SHA256SUMS.txt` 包含三个安装器的 SHA-256。发布草稿只有在附件上传完成且服务器端大小/摘要核对通过后才标记为可验收；公开发布仍需维护者最终确认。
